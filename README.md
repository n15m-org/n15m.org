# n15m.org

The website for the n15m Network of Momentum.

## Development

```bash
pnpm install
pnpm dev
```

Open <http://localhost:4321>.

## Verification

```bash
pnpm check
```

`pnpm check` verifies formatting, Astro diagnostics, and the production build.

## Deployment

The GitHub Pages workflow is manually triggered from the Actions tab.
